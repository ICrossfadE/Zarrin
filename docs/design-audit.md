# Аудит дизайну — 2026-11-17

Джерело: файл `TvAKe7WblMMsW6Zxc3ikpp`, сторінка **Free Blog website Template design**, відкрита у настільній Figma. Власник погодив цей спосіб після недоступності MCP. `get_design_context` не викликався; відповідність не підтверджена MCP або автоматичним pixel-diff.

## Отримано з оригіналу

- 28 фреймів, зокрема Style Guide `401:1612`, License, Buttons & Components; desktop 1440, tablet 1024 та mobile 375 px.
- Основні маршрути й node IDs — у [figma.md](figma.md). Серед пар desktop потрібні другі експортовані копії з суфіксом `-1`; вони відповідають ID із документації. Тексти й геометрія пар збігаються.
- Палітра: purple `#7C4EE4`, текст `#333333`, вторинний `#666666`, приглушений `#999999`, білий `#FFFFFF`; фон сторінок `#FAFAFA` підтверджений фреймами.
- Raleway — заголовки, UI, header/footer, hero та newsletter; Roboto — картки й текст статті. Стилі desktop: hero 64/86, заголовки сторінок 48, featured title 32/45, картки 24/32, body 16/24. Newsletter 52/48. Mobile: hero 36/40, заголовки сторінок 24, картки 18, body 12/18.
- Desktop-контейнер 1232 px, mobile-відступ 24 px. Header 98/74 px. Радіуси: 16 px для desktop-карток, 8 px для кнопок/полів, менші значення у mobile.
- Картки desktop: фото 400×360; mobile: близько 287.21×258.49. Hero: 608×576 і 327×330. Матриця crop hero містить віддзеркалення та нерівномірний scale; відтворена за SVG pattern.
- Mobile Home показує три recent-картки й повторює їх у Popular; Blog mobile повторює ці три двічі. Це збережено. Mobile-шаблон статті має дві related-картки.
- Знайдено Contact mobile `401:2095` і 404 mobile `401:2188`. Contact mobile має одну колонку полів Name → Phone → Email → Subject → Message і не містить кнопки надсилання. Desktop-кнопка є інертною.

## Рішення реалізації

- Проміжні брейкпоїнти 640/800/1200 px, hover/focus і параметри reveal є інженерними рішеннями, не токенами Figma.
- Reveal: 24 px по Y, 0.65 s, `power2.out`, одноразово; `gsap.matchMedia` лише для `prefers-reduced-motion: no-preference`, cleanup через `revert()`. SSR/CSS не приховують контент.
- Іконка пошуку отримала локальний діалог пошуку за заголовками. Його окремого макета немає. Escape закриває діалог; мережевий пошук не використовується.
- Нативний `details` забезпечує mobile navigation без JS; клієнтський код закриває його після переходів та Escape.
- Соцпозначки статичні: URL у макеті не задані. Контакти та copyright відтворені як демонстраційний текст. У макеті адреса London, але статична карта New York; оригінальну карту збережено.
- У статей 9 коротких локальних прикладів і один повний текст шаблону. Це не реальні редакційні публікації. Категорії/дати та мовні помилки макета здебільшого збережені.
- Webpack — локальний workaround для відтвореної помилки дочірнього процесу Turbopack. Сервіси та конфігурація мережевої інфраструктури не змінювалися.

## Межі перевірки

Перевірки й фактичні результати — у [task/003](../task/003-figma-pages.md). Виконана візуальна звірка ключових областей та перевірки DOM/геометрії й адаптивності; повний автоматичний pixel-diff не виконувався. Локальний SVG-renderer без установлених системних шрифтів показує неправильні переносы; його PNG використовувалися для композиції та ресурсів, а типографіка бралася з властивостей шарів і локальних Raleway/Roboto.

Інструмент браузера не надає емуляцію `prefers-reduced-motion` чи вимкнення JavaScript. Ці режими перевіряються статично за умовами GSAP, базовими стилями та SSR-виводом; окрему інтерактивну перевірку цих режимів не слід вважати виконаною.
