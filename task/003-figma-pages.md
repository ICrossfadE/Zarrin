# 003 — Спроба відтворення сторінок Figma

## Поточний результат — виконано через настільну Figma

Статус на 2026-11-17: локальний frontend реалізовано з погоджених нативних експортів. Попередні блокери MCP нижче збережено як історію; вони більше не блокують створену UI-версію.

Зроблено:
- Відкрито потрібний файл у Figma через computer-use; підтверджено сторінку **Free Blog website Template design**. Прочитано всі авторські файли, збережено попередні зміни AGENTS.md, навички та задач.
- Експортовано 28 фреймів із текстом і геометрією; окремий початковий Style Guide дає 29 SVG-файлів. Знайдено mobile Contact `401:2095` і 404 `401:2188`.
- Отримано 18 унікальних оригінальних растрових ресурсів та окремі векторні групи. Підтверджені параметри й походження: `docs/design-audit.md`, `docs/assets.md`. Сирі експорти й скриншоти локальні, виключені з Git.
- Реалізовано `/`, `/blog`, `/blog/[slug]`, `/about`, `/contact`, системну 404, 10 типізованих локальних статей через один шаблон, спільні компоненти, локальні шрифти, пошук, mobile menu та GSAP reveal.
- Форми не містять form/submit, handlers надсилання, API, Server Actions, збереження або success-state. Соцпозначки статичні через відсутність destinations. CMS та зовнішні сервіси не підключалися.
- Виправлено знайдені під час перевірки відступи, crop hero, порядок і розміри mobile Contact, закриття меню після переходу та перший Escape у search input.

Команди та результати:
- `npm run lint` — успішно, без попереджень. Початкові зауваження щодо явного alt і require у допоміжному скрипті виправлені.
- `npm run typecheck` — успішно; локальні fixtures перевіряються через `satisfies Post[]`.
- `NEXT_TELEMETRY_DISABLED=1 npm run build` — успішно; 16 пререндерених сторінок, зокрема 10 slug.
- Початковий Turbopack відтворив `node process exited before we could connect` для PostCSS у sandbox і поза ним. Штатний Webpack пройшов; `dev` і `build` переключені на `--webpack`. `agentRules: false` прибирає лише автоматичний блок Next.js, зберігаючи авторський AGENTS.md (його початкова стороння зміна залишилася).
- `node task/smoke-check.mjs` проти production-сервера — успішно: 200 для Home/Blog/About/Contact і двох різних slug; 404 для `/missing-page` та `/blog/missing-article`. HTML містить main/h1 без JS, не містить form або початкової inline opacity:0.
- Усі 28 файлів public/images непорожні. SHA256-префікси всіх 18 растрових оригіналів збігаються з байтами експортів.
- Браузер: 30 комбінацій шести типів сторінок та ширин 360/390/768/1024/1440 — без горизонтального overflow. Уточнення: Windows-скролбар займає 15 px; viewport 390 дає canvas 375 px.
- Візуально перевірено hero, картки, article, About, Contact, 404, newsletter/footer. Звірено slot/callsite та геометрію ключових ресурсів; усі 9 desktop-карток Blog завантажені з фото 400×360. Фінальний Home після прокручування: усі видимі ресурси завантажені, без помилок/попереджень консолі.
- Пошук знаходить VR-статтю; Escape закриває діалог і повертає focus. Tab дає видимий 3 px focus-visible на Contact Us, cursor pointer; hover кнопки змінює колір. Mobile menu відкривається і закривається після переходу на About.
- Contact: введення тестового Name, Enter та Send Message не змінюють URL, не створюють submit; query порожній. Мережеві API/обробники відсутні в коді. Мережевий перехоплювач браузера недоступний, тому окремий network trace не записано.
- `git diff --check` — без whitespace errors; початкові зміни власника не скидались. Lint/typecheck/build після остаточних правок повторно пройшли.

Обмеження:
- MCP та автоматичний pixel-diff не використовувалися. Повної піксельної тотожності не заявляємо.
- Reduced motion перевірено статично: GSAP працює лише при no-preference і має cleanup. Інструмент браузера не підтримує емуляцію цього режиму. HTML без JS перевірений HTTP/SSR, але окрема браузерна сесія з вимкненим JS не запускалась.
- Дев'ять статей мають лише короткі демо-уривки; фінальні контент, контакти, соціальні URL та права на медіа залишаються питаннями до публікації.
- Нативний експорт додав/узгодив metadata експорту 28 фреймів: SVG, 1x, без outline text, з id. Геометрію дизайну не редаговано. Початковий PNG Style Guide через особливість set_value у діалозі зберігся у `%LOCALAPPDATA%/Figma/app-126.11.9/Style Guide.png` (1 463 029 байтів), поза repo; він не видалявся. Подальші SVG збережені у правильну локальну папку явним набором шляху.

Залишено production-перегляд: `npm start -- --hostname 127.0.0.1 --port 3100`, адреса `http://127.0.0.1:3100`. Скриншоти `docs/design-exports/home-desktop.jpg`, `home-mobile.jpg`; звіт `browser-checks.json`. Наступний крок: перегляд власником і точкові дизайн-коригування за потреби; CMS/публікація потребують окремого запиту.
