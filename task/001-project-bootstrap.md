# 001 — Початкова підготовка Zarrin

Статус: виконано.

## Обсяг

Ініціалізувати локальний Next.js проєкт з App Router, TypeScript та Tailwind CSS. Підготувати документацію й інструкції для агента. Сторінки з Figma, GSAP-анімації та CMS запланувати на наступні етапи. Жодних зовнішніх сервісів чи публікації.

## Коментар для власника

Фразу «розгорнути Nextjs проєкт і більше нічого» трактуємо як локальну ініціалізацію, а перелік сторінок — як вимоги до майбутньої реалізації. Figma не вдалося прочитати через доступний вебінструмент; точні токени, шрифти й розміри не вигадуємо. Усі надані посилання будуть збережені для наступного етапу.

## Результат

Створено каркас App Router, конфігурації TypeScript/Tailwind/ESLint, package-lock.json, технічну головну сторінку, README, AGENTS.md та чотири документи у docs. Немає реалізації дизайну, CMS, GSAP або зовнішніх сервісів. Git та remote не створювалися. Тестовий сервер після перевірки зупинено.

## Перевірки

- `npm run lint`: успішно, без попереджень.
- `npm run typecheck`: успішно.
- `npm run build`: успішно, статичні `/` і стандартна `/_not-found`.
- `npm start -- --hostname 127.0.0.1 --port 3100`: успішно; `/` повертає HTTP 200 і технічний текст Zarrin; `/missing-page` — HTTP 404.
- npm audit під час встановлення: 0 vulnerabilities. Це результат на момент встановлення, не постійна гарантія.

## Технічні примітки

Зафіксовано Next.js 16.4.6, React 19.3.1, Tailwind 4.3.5, TypeScript 6.0.3. TypeScript 7 не підтримується поточним typescript-eslint, тому обрано сумісну гілку 6. ESLint 9.39.5 залишено через peer range eslint-plugin-react (`^9.7`, без підтримки 10); npm позначає гілку 9 як таку, що більше не підтримується. Перед подальшим оновленням переглянути сумісність всього набору плагінів.

Sandbox блокував npm/DNS, локальні сокети та дочірній процес Turbopack. Встановлення, production build і HTTP smoke-перевірку виконано через дозволений запуск поза sandbox. Для фінальної збірки та тестового сервера задано NEXT_TELEMETRY_DISABLED=1.
